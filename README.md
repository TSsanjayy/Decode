# 🧠 DECODE

### AI-Powered Code Analysis & Explanation Tool

DECODE is an AI-powered code analysis tool designed to help beginners understand programs more easily.

It analyzes the submitted code, divides it into meaningful logical segments, explains what each section does, identifies important functions and variables, and provides time and space complexity analysis.

---

## ✨ Features

- 🔍 Breaks code into meaningful logical segments
- 💡 Provides beginner-friendly explanations
- 🐛 Detects common syntax and logical issues
- 📊 Analyzes time complexity
- 💾 Analyzes space complexity
- 🔑 Identifies important functions and variables
- 🏷️ Identifies important programming keywords
- ⚡ Provides code improvement suggestions
- 📚 Gives line-by-line explanations
- 🤖 Uses Google Gemini AI for intelligent analysis
- 🎨 Interactive Streamlit interface
- 🧑‍💻 Designed especially for programming beginners

---

## 🛠️ Technologies Used

- **Python** – Core programming language
- **Streamlit** – Web application interface
- **Google Gemini API** – AI-powered code analysis
- **python-dotenv** – Environment variable management

---

## 🤖 AI Model

DECODE uses the **Google Gemini API** to analyze and explain user-submitted code.

The application sends the user's code and analysis instructions to the Gemini model and displays the generated explanation through the Streamlit interface.

The model can be selected from the application's settings.

---

## 🔐 API Key

DECODE requires a **Google Gemini API key** to perform AI-based analysis.

The API key can be entered directly through the application's sidebar.

For local development, the API key can also be stored in a `.env` file:

⚠️ Limitations

DECODE currently has some limitations:

Requires an internet connection
AI analysis depends on the Gemini API.
Requires a valid Gemini API key
Without an API key, AI-powered analysis cannot be performed.
API usage limits
Free Gemini API usage is subject to Google's current rate limits and quotas.
Limits may vary depending on the selected model and account.
AI-generated explanations
Explanations are generated by an AI model and may occasionally contain mistakes.
Very large programs
Extremely large code inputs may take longer to process or may exceed model input limits.
Programming language support
Analysis quality depends on the selected language and the Gemini model's ability to understand that language.
Response speed
The application may appear slow when the Gemini API takes longer to respond.
