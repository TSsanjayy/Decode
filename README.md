# DECODE 🧠

AI-powered code analysis tool that helps beginners understand programs.

## ✨ Features

- 🔍 Breaks code into meaningful segments
- 💡 Explains what each segment does
- 📊 Analyzes time complexity
- 💾 Analyzes space complexity
- ⚙️ Identifies functions and variables
- 🔑 Identifies important keywords
- 🤖 Powered by Google Gemini AI
- 🎨 Interactive Streamlit interface

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini AI
- python-dotenv

## 🚀 How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install the required packages.
4. Add your Gemini API key to a `.env` file.
5. Run the application using Streamlit.

```bash
streamlit run app.py
